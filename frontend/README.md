# I4C Cybercrime Proactive Framework — NPM + Vite Frontend (`frontend/`)

This folder contains the **NPM + Vite** frontend application featuring the **ASTRO** cosmic editorial UI, persistent Home & Developer navigation, and all 6 interactive cybercrime intelligence modules.

**Architects & Developers:**
- Shantnu
- Jatin Kumar
- Akshat Sharma

**Developer:** Shantnu K. Swami

## Quick Start

```bash
cd frontend
npm install
npm run dev
```

The Vite dev server starts on **`http://localhost:5173`** and proxies `/api` requests to the Node.js backend at **`http://localhost:5000`**.

## Production Build

```bash
npm run build
npm run preview
```
